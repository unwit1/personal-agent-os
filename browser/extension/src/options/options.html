Agent OS for Firefox

One extension for capture, content filtering and letting Agent OS operate your tabs.

Hide things

Hover any post, mod, work or thread and click ⊘, or right-click it and choose Agent OS → Hide…. The pill in the bottom-left corner shows what was hidden; click it to peek.

Capture

Everything from the Universal Capture userscript is built in: per-item save buttons, the browser journal, Discord indexing and Amazon cart import. Use the toolbar button for the full menu.

Agent OS bridge

The extension pairs with agent-os browser-bridge automatically through the native helper, keeps the bridge running and registers each tab so browser.execute works.

Setup checklist

    If you still have the Tampermonkey copy of Agent OS Universal Capture or the Reddit Subreddit Hider add-on enabled, turn them off; this extension replaces both and running them together duplicates captures.

    Scheduled tasks

    Record a sequence of clicks, form entries and a sign-in once, and Firefox repeats it at the times you choose. Passwords are never recorded: a login you save here is kept in Windows Credential Manager and filled only when the task runs. Tasks run while Firefox is open; one missed while it was closed runs when Firefox starts (within 6 hours).
