# Compile project context

Run `agent-os context <project> "<task>"` before meaningful project work.

Use the returned project policy, current state, handoff, exact search matches,
and matched skills. Inspect additional files only when the task packet points to
them or when a concrete gap remains. Never replace project-local authority with
cross-project memory.

If the project has uncommitted work, preserve it and determine whether it
overlaps the requested task before editing. After material changes, validate the
affected scope and write a compact handoff.
