# Capture Improvement

Use when a technical conversation reveals a reusable bug fix, optimization, architecture improvement, missing regression, or repeated workflow.

Resolve the project, respect privacy, search active candidates for duplicates, and store only a concise observation, evidence references, suggested direction, acceptance criteria, and risks. Default to `candidate`; use `ready` only when implementation evidence is sufficient. Never store raw documents, OCR, credentials, employee/applicant/payroll data, or chat transcripts. A candidate is a hypothesis until reproduced and tested.
