# Capture Change

Use for a concrete engineering change discovered during project work.

1. Resolve one registered project and respect its privacy boundary.
2. Store an abstract title and summary, references instead of copied evidence, and no raw chat or source document text.
3. Search for an existing change before creating one.
4. Advance lifecycle status only with the required diagnosis, implementation, and validation evidence.
5. Keep ordinary context compact; fetch the full record only when its id is relevant.
6. Export only through the explicit safe projector. Google is never canonical or required.
7. Promote reusable lessons only from verified changes and through candidate review.
