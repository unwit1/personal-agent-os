### Orchestrator findings

- **O1 (high): a placeholder validator was baked into every node.** `projects/ingester-engine/state.json` listed `python tools/validate_repo.py <downstream-repo>`, and cmd.exe parses `<…>` as redirection ("The syntax of the command is incorrect."). In run 1eecf1, 4 tasks whose own tests all passed burned 2 model escalations each and then failed or deferred. Acceptance: (1) registry/state validation rejects `validation_commands` containing `<placeholder>` tokens; (2) a validator failing with a shell syntax or command-not-found error is classified as a host failure (no model escalation, no retry), and reported once as a deferred host action.
- **O2 (high): non-independent review churn.** With Codex in quota cooldown, all 5 review rounds on bench-script and on parity-manifest-test were claude-code reviewing claude-code work (`independent_provider: false`). Each round raised new low/medium findings, which ended in operator gates G1 and G2 and consumed most of the 40-launch budget. Acceptance: (1) when no distinct provider is available, either wait for the other provider's reset (if it is within `wait_for_reset_seconds` or a configurable longer bound) or cap same-provider review at 2 rounds; (2) after round 2, findings of severity < medium are recorded as non-blocking follow-ups instead of reopening repair; (3) metrics report reviews per task and their independence.
- **O3 (medium): gates block unattended campaigns.** `orchestrate_decide` is refused to the supervising agent by the client permission classifier, so every `unresolved_review_findings` gate stalls `--until-done` until the operator returns. Acceptance: a documented run policy (for example `auto_accept_review_findings_below: medium` after N rounds) that the orchestrator applies itself and records, without an agent self-approving.
- **O4 (info): CC-5 is still GAP** (`docs/orchestrator-os/readiness.md:39`): `max_launches` exists, but there is no token or money cap. Runs remain behind CC-1. Priority stays as in bootstrap §7.4 (ORCH-A first, CC-5 second).
