# Skyrim Modding Research Frontier

Updated: 2026-09-24

The broad technical surface is now covered, but Skyrim modding is not a finite static corpus. These areas should remain “research on demand” rather than falsely marked complete.

## Continuously changing

- exact Skyrim runtime/SKSE/Address Library/native-DLL compatibility;
- Creation Kit executable versions and CKPE support;
- Community Shaders feature architecture;
- SkyPatcher grammar/categories;
- OAR/Pandora/FSMP releases;
- xEdit schemas/cleaning behavior/partial-form support;
- DynDOLOD alpha releases and generation rules;
- mod-manager/Wabbajack behavior;
- Nexus-hosted framework changelogs.

## Research-on-demand protocol

When Agent OS encounters a question not supported by current evidence:
1. identify subsystem and exact versions;
2. search current upstream source/docs first;
3. inspect the user's actual plugin/assets/logs when available;
4. compare against the knowledge repository;
5. store new evidence as a candidate;
6. validate/resolve contradictions;
7. promote the durable finding with provenance and version scope.

The goal is not to pretend the wiki is permanently exhaustive. The goal is to make gaps explicit and automatically convert future troubleshooting/research into reusable knowledge.
