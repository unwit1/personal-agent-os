## Useful groupings

### Actor AI/personality
0–5: Aggression, Confidence, Energy, Morality, Mood, Assistance.

### Skills
6–23: the 18 player skills from One-Handed through Enchanting.

### Primary resources and regeneration
24–29: Health, Magicka, Stamina and their base regeneration rates.

### Movement/inventory/combat
30–45 include Speed Mult, Inventory Weight, Carry Weight, damage and resistance values.

### Script/general-purpose variables
68–77: Variable01 through Variable10. Vanilla packages/quests use these as generic actor state channels; mod authors should avoid assuming an unused VariableXX is globally free without checking the target actor/framework.

### Skill modifiers
96–113: modifiers for the 18 player skills.

### Skill advance values
114–131: accumulated advancement/progress channels for the 18 player skills.

### Power modifiers
135–152: power modifiers associated with player skills.

### Late/internal state values
153–163 include Dragon Rend, Attack Damage Mult, resource-rate multipliers, Werewolf/Vampire Perks, grabbed-state values and Reflect Damage.

## Semantics

- ActorValue ID is an engine enum, not a dynamic registry: mods cannot create arbitrary new true ActorValues simply by naming them.
- Base, permanent, temporary and damage modifiers are separate layers on many ActorValues.
- Some entries are internal state channels and should not be treated like ordinary stats.
- xEdit intentionally labels several IDs as Unknown in this release; preserve that uncertainty rather than inventing names.
- Frameworks can emulate new progression/stat systems through Globals, StorageUtil/native state or Custom Skills without extending this enum.
