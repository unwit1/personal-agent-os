## Use

This is the canonical top-level record-type routing table for Skyrim plugin analysis. When an unknown record signature appears, first determine whether:
- it is one of these supported TES5/SSE signatures;
- it belongs to another Bethesda game;
- it is a group/subrecord signature rather than a top-level record;
- it is unsupported/newer official data requiring a newer xEdit definition.

## Important distinctions

- **Record signature** such as `NPC_`, `MGEF`, `CELL` identifies a top-level record type.
- **Subrecord signature** such as `EDID`, `FULL`, `VMAD`, `DATA` identifies a field/container inside one or more record types.
- The same subrecord signature can mean different data in different parent records.
- A four-character string in an archive/NIF/config is not automatically a plugin record signature.

## Maintenance

Regenerate/diff from xEdit's own definitions whenever the pinned xEdit release changes. The preferred long-term source is xEdit-native xDump Export, documented in `research/xedit-native-schema-extraction.md`.
