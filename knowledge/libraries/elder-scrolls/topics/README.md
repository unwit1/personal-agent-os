# Elder Scrolls Topic Library

Human-browsable topic layer built above the source corpus.

Each topic file is a living dossier. Claims should eventually point back to source records/evidence rather than treating summaries as primary sources.

## Topic status
A topic can be stub, developing, or mature. Stubs are browse/navigation anchors and must not be mistaken for complete lore summaries.
