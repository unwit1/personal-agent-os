# Sources

Source-specific manifests and provenance records. Planned primary sources include UESP, The Imperial Library, and direct game/plugin extraction.

## Imported source corpora

- [Apocryphal Library book corpus](./apocryphal-library/) — 784 directly extracted BOOK records from `LB_ApocryphaBooks.esp`, retained as a provenance-scoped compilation source.
- [BF Books ESO corpus](./bf-books-eso/) — 4,277 directly extracted `BOOK` records from `BF_Books_ESO.esp`, stored as full-text 50-book JSONL batches with source and text hashes.
