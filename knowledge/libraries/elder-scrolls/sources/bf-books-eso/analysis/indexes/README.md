# BF Books ESO retrieval indexes

Generated from the 86 reviewed-schema analysis batches.

- `retrieval-*.jsonl` mixes typed book summaries, existing-topic backlinks, controlled lore tags, and unresolved entity candidates.
- `claims-*.jsonl` contains only evidence-grounded, **unreviewed** claim candidates.
- No candidate in these indexes is promoted to canonical fact merely because it was extracted.
- Contradiction review is generated separately from relation signatures and negation polarity.
