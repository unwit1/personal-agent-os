# Apocryphal Library implementation collections

The compilation plugin groups books through Skyrim `CONT` containers and `LVLI` leveled lists. These groupings are useful for understanding the compiler's organization and for browsing the corpus, but **they are implementation metadata, not evidence that a grouping is canonical lore**.

- Containers in plugin: **31**
- Containers directly holding imported books: **20**
- Leveled lists in plugin: **40**
- Leveled lists directly referencing imported books: **25**

## Notable compiler-defined collections

The plugin includes explicit named containers such as **Collected Pages from the Warp in the West**, **Collected Pages from the Battlespire**, **Collected Pages from Stros M'kai**, **Collected Pages from Sotha Sil**, **Collected Pages from the Oblivion Crisis**, and **Collected Pages from Vvardenfell**. These names provide useful source-discovery leads, but individual records still require source verification before their continuity status is promoted.

The complete membership graph, including FormIDs and per-book paths, is stored in [`technical/container-membership.json`](./technical/container-membership.json).
