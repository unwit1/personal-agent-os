Kontrau so Tribunalo

dahk K'Thassvi

<p align="left">
<img src='img://Textures/Interface/Books/Illuminated_Letters/S_letter.png'>o mahkm-titolitaj dioregauw dahk Rahksdayn, kaj ciuj tiuj ahklfauw kiuj kompatinde faris prahkgon al jheaj mortintaj prapatrauw antaue, malpermejhes so sagan praktikon dahk nahkromancio.

so ironio ci tiahk ahkstas ahknorma, car ci tiuj ahklfauw uzas bonegan uzon dahk kadavro-ligado ahkn jheaj klopodauw protekti ci tiujn tombauwn. so osto-migranto ahkstas psohkj fortika ahkkzemplo dahk zombio, kun ahkc so pli malgrandaj verjheauw kapabsauw kauzi tahkruran malsanon al tomborabistauw. so pli grandaj vahkrjheauw ahkstas ja tahkruro, car iliaj afliktauw povas ahknradikigi sub so pahkzo dahk jhea propra malfortahkco.

Pli impona ankorau ahkstas so osto-jhenjoro, kiu ahkstus psohkj mirinda bsosfemo dahk iu ajn alia krahkinto. Faritaj ahkl so ostauw dahk multobsauw ahklfauw, fauwe so sama familio, ili dahkfendas jheajn tombauwn fahkroce.

so Tahkmplo dahk Rahksdayn kaj giaj ordigantauw dahkvigas tiun praktikon, kaj tamahkn nahkromancio daurahk ahkstas kontrausohkga. Kia hipokriteco ahkstas ci tio? ahkbsohk so tri rahkgauw sahkrcas limigi so praktikon al jhe mahkm. Kaj gi ahkstas kauzo, kiun ni povas kompreni, car ni audis so rakontauwn pri tio, kahk ili farigis diauw.

Gi ahkstas vahkra! Uzante so psohkj potencan nahkkromantan artefakton ahkn so tuta konata krahkado, ci tiuj diauw stahklis potencon dahk so krahkinto dahk so mondo! Sahk ili volus, ili povus igi Rahksdayn rifugejo por ciu nahkromantika scio. Sahkd ili casas nin.

Sahkd nahk plu; car sango ahkstas ahkn so tajdo. Ilia maljunega masomiko Dagoth-Ur, so Sharmat, ahkstas vahkkita, kaj li trovis manieron uzi so antikvan koron por li mahkm. Ni sahkndos niajn sksovacetantauwn al Rahksdayn kun sahkkreta mijheo, fari kontakton kun so Sahksa Domo, kaj kune ni klopodos alporti so vahkran arton rahke al tiu sondo. Nahk plu tomborabistauw dahkvos kajhe antau so autoritatauw pro stahksodo dahk tombopolvo kaj ostfaruno ahkl malnovaj kriptauw.

Ihkn so nomo dahk Mola Bal kaj Clavicus Vile!
