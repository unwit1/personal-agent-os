# Extracted books

All **784** `BOOK` records from `LB_ApocryphaBooks.esp` are preserved here as individual UTF-8 text files.

File names use `<FormID>-<title-slug>.txt` so duplicate titles remain distinct. Exact titles, editor IDs, and text hashes are in `../source-manifest.json`.

Two records have empty `DESC` text; they are retained as empty files rather than dropped.

Text is intentionally not normalized. Skyrim markup such as `[pagebreak]`, alignment tags, and `img://` references remains in place.
