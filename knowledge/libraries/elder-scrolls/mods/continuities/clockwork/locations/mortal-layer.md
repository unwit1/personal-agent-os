# Mortal Layer

Continuity: `tes.mod.clockwork`

The Mortal Layer is a named area of Nurndural used during *Crystalline Heart*. When Amalgam retreats behind a portcullis, the player needs to repair a nearby ballista control. A written note indicates that a compatible replacement lever handle can be found in a house at the far end of the Mortal Layer.

No broader function for the area's name is asserted without further evidence.
