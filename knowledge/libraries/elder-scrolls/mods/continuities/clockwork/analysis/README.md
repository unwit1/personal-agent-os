# Clockwork analysis

This directory contains interpretive synthesis derived from the evidence layers in this continuity. It is **not** a replacement for the underlying dialogue, quest, book, event, or claim records.

- [Themes](themes.md)
- [Source reliability](source-reliability.md)
- [Contradictions and revisions](contradictions-and-revisions.md)
- [Character arcs](character-arcs.md)

Analysis should always preserve:
1. whether a point is directly stated, inferred, or revised later;
2. whose testimony supports it;
3. when in the story the player can know it;
4. that Clockwork-continuity claims do not silently overwrite Bethesda continuity.
