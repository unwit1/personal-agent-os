# Keys

Continuity: `tes.mod.clockwork`

## Mausoleum key

Lamashtu holds the key needed to access the castle mausoleum passage into Nurndural during *Steam-Powered*.

Evidence: `QUST 052908C1 stages 70-80`.

## Terminus gate key

Lahar can replace a lost key for the Terminus gates.

Evidence: `INFO 054F2761`.

## Ludwig / Master Bedroom wardrobe key

During *A Bed of Dust*, one of Ludwig's journals contains a key associated with a wardrobe in the Master Bedroom.

Evidence: `QUST 05337FC1 stage 30`.

These are kept as distinct key roles even where object FormIDs are not yet promoted into the browse layer.
