# Steam pipe sections

Continuity: `tes.mod.clockwork`  
Object type: repair component

The main steam pipeline between Nurndural and Clockwork Castle has ten breached sections during *Steam-Powered*. Lahar says all ten must be replaced.

Replacement pipe sections can be scavenged in Nurndural or, if the player knows how to work Dwemer metal, cast at local forges.

Repairing the ten ruptures restores steam to the castle and reactivates systems including the Travel Machine, Work Room, heating, and Glass Garden.
