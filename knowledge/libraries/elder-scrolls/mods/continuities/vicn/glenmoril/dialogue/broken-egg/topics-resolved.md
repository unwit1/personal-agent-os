## Chronological significance

These rows directly establish a **pre-St.-Bazura state** in which both Lalanoah and Brandt remember Jhunal and actively search for him.

St. Bazura later shows:
- Lalanoah no longer knows anyone named Jhunal;
- Brandt denies the owl-search memory and substitutes a treasure-hunt memory.

This makes the later selective-forgetting evidence a clear memory transition rather than simple ignorance.
