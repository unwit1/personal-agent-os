# GLENMORIL source-text layer

This directory preserves and indexes textual records extracted from the user-supplied `Glenmoril.esm`.

## Provenance policy

Each text should retain:
- source plugin;
- source SHA-256;
- record Form ID;
- Editor ID;
- displayed title;
- source/continuity classification;
- whether the text is GLENMORIL-specific or a reused Elder Scrolls text.

Reused Bethesda/ESO texts must not be attributed to Vicn merely because a copy exists in GLENMORIL.

## Storage policy

Primary text is stored source-scoped so derived lore pages can cite the exact record rather than repeatedly reparsing the ESM. Interpretations belong in entity/concept/analysis pages, not in the source transcription.
