# Yelem source corpus

This directory groups BOOK records explicitly presented as **Yelem's Note** in the supplied `Glenmoril.esm`.

Current normalized families:

- Pailune
- Sithis
- Laza
- Shezarr
- Lizard
- CsO

Family pages are retrieval/index layers, not replacements for individual BOOK records. The next normalization level is one file/structured record per note, preserving Form ID, EDID, title and exact source text.

## Cross-family retrieval

The corpus should be retrieved together when researching:
- Yelem;
- the Spring;
- Laza;
- Owl imagery;
- the Great Cat;
- Shezarr;
- Egg/cocoon/shell imagery;
- curse/taint;
- body/machine transformation;
- nightmares and possible futures.

Claims remain attributed to Yelem unless corroborated elsewhere.
