# Dialogue ordering note

INFO order is semantically important.

xEdit documents that the engine evaluates INFO records in effective order within a DIAL, and that the ordering rules can involve initial file order and `PNAM - Previous INFO` relationships. citeturn0search2

Therefore the GLENMORIL dialogue corpus must preserve:
- original record encounter order;
- DIAL parent;
- PNAM links;
- response number;
- condition order.

A convenient alphabetical or FormID sort may be offered as a secondary index, but must never replace the source ordering data.
