# St. Bazura dialogue pass 33

This pass moves St. Bazura from structural setup into direct dialogue ingestion.

## Method

For branch/topic dialogue, each INFO record's `GetIsAliasRef` condition was decoded and mapped to the `zzzGHmq06Sub01` QUST alias table. This provides exact speaker attribution independent of editor-ID naming.

SCEN dialogue uses the existing SCEN Actor ID → alias → DIAL → INFO pipeline.

## Result

112 new exact response rows were resolved, bringing the tracked corpus to 285.

The most consequential result is the record-level resolution of **Jhunal the White** as the quest's White-Owl actor, accompanied by an explicit selective-forgetting pattern.

A second major result is Kalka's succession language around Lalanoah and “the next Hamah,” which should be treated as a high-priority identity/role question in subsequent late-Act-2 material.
