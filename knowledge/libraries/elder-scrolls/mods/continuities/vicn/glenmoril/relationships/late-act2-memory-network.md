# Late Act 2 memory network

A recurring late-Act-2 cluster now has multiple independent source anchors:

**Quagmire** is framed as a nightmare/memory space; **Oneiromancer** material concerns erased or removed information; **Zuzu's Memories** appears among quest targets; **Forgotten Vessel/Jhunal** is paired with dialogue about people not remembering Jhunal; and **St. Bazura** reconnects these threads with Lalanoah, the Owls and earlier Witch Hunt material.

This supports **memory / forgetting / preserved identity** as a high-value retrieval theme in late GLENMORIL.

It does not yet establish one shared supernatural mechanism. Lorekeeper should retrieve these nodes together for analysis while preserving their separate causal claims.
