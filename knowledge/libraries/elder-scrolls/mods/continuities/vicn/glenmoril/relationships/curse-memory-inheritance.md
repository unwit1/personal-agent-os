# Curse / inherited memory thread

Primary source: **Ebonwall** Ja'zel topic dialogue.

Ja'zel warns the player:
- memories can be **passed down through the curse**;
- because of this, the player must never forget who they are and what it feels like to be themselves;
- otherwise they risk becoming a monster.

## Cross-links

This should be retrieved with:
- Ozwald saying the player inherited **Felix's curse**;
- Ozwald feeling Felix is still somehow alive through the player;
- Romion checking **memory clarity** during blood-curse diagnostics after Tainted Orphan;
- later Jhunal memory alteration/forgetting evidence.

## Ontology guardrail

This directly establishes **memory transmission as a claimed property of a curse**, but it does not prove:
- whose memories are transmitted in every case;
- that all “curse” terminology refers to one mechanism;
- that the player is Felix;
- that memory inheritance equals reincarnation or possession.
