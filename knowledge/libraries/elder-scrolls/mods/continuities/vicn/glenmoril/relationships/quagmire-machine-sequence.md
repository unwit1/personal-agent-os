# Quagmire machine sequence

The Oneiromancer quest contains a connected authored machine sequence:

1. Tuning Box scene — `0171EA zzzGHMq05ScBrBox`
2. Gate Open scene — `01724F zzzGHMq05ScGateOpen`
3. Ozwald receives `zzzGHMq05OzwaldWarpToQuagmire`
4. Quagmire scenes and Oneiromancer encounter
5. Hologram scene — Romion directs recovery of the Oneiromancer's memories through a terminal

## Supported claims

- The expedition uses machinery as part of physical entry into Quagmire.
- FL-4N participates directly in the gate-opening sequence.
- Ozwald is explicitly assigned a warp-to-Quagmire package.
- Romion later directs memory extraction through a terminal.
- Romion attributes the Quagmire machinery to Dwemer attempts to settle the realm.

The last point remains **Romion's attributed historical explanation** rather than independently established history.
