# Sinak creature family

Continuity: tes.mod.vicn.unslaad

UNSLAAD implements a four-branch Sinak creature family:

- **Mal-Sinak** — HM Rat Race
- **Rein-Sinak** — HM Cat Race
- **Ru-Sinak** — HM Spider Race
- **Pogaan-Sinak** — HM Wisp Race

Each branch has ordinary, summon, and/or stronger boss-like forms.

## Ordinary forms

Ordinary hostile forms:
- belong to **Owl Faction**;
- use their branch-specific custom race;
- generally drop **Woodland Man Roots** through the shared HMCreature death list.

Summoned versions use the same custom races but may omit Owl Faction membership because summon hostility/alliance is handled separately.

## Weapon symbolism

The stronger Sinak forms therefore connect physically to:
- Anga-Mora-named weapons;
- a Herma-Mora-named weapon;
- Woodland Man Roots;
- Owl Faction.

## Interpretation boundary

This is strong implementation evidence for a shared creature family embedded in the Owl/Woodland-Man/Herma-Mora network.

It does **not** by itself prove that:
- every Sinak is literally an offshoot of Oohoo'Laf;
- Anga-Mora and Herma-Mora are interchangeable names;
- their summon tomes imply the same ontology as natural/hostile forms.

Keep creature lineage, faction membership, and metaphysical origin as separate evidence layers.

## Summon-chain resolution

Each branch has a deterministic BOOK -> SPEL -> MGEF -> summoned-NPC chain:
- Conjure Mal-Sinak -> summoned Mal-Sinak
- Conjure Rein-Sinak -> summoned Rein-Sinak
- Conjure Ru-Sinak -> summoned Ru-Sinak
- Conjure Pogaan-Sinak -> summoned Pogaan-Sinak

The summoned forms use the same custom branch races as hostile forms but omit Owl Faction and the Woodland-Man-Roots death list. This strongly supports **summoned proxy of the same creature archetype**, not the same hostile individual.
