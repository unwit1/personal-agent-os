## Classification

**Reused unofficial developer text / unlicensed Elder Scrolls text.**

The embedded text matches **Sermon Zero of the Thirty-and-Six-and-Nine Sermons of Vivec**.

External source histories identify the text as:
- written by former Bethesda developer **Douglas Goodall**;
- originally published around **March 2002** in a forum roleplaying context;
- not included as an in-game Morrowind book;
- generally classified as an unofficial/unlicensed developer text.

The distinctive opening, encoded block, and "true key / lesser or false key" ending match the known Sermon Zero text.

## Lorekeeper handling

- Do not attribute the prose to Vicn.
- Do not promote it into released-game canon merely because UNSLAAD embeds it.
- Store it in the same broad provenance class as other developer/apocryphal texts.
- UNSLAAD's decision to include it remains valid evidence for the mod's interpretive source pool.

## Relation to Sermon 37

Sermon 37 and Sermon Zero have different provenance:
- Sermon 37 = official ESO in-game text.
- Sermon Zero = unofficial developer/forum text by Douglas Goodall.

They should not share a generic "apocryphal" tag that erases this distinction.

## Provenance closure

For ingestion purposes this provenance question is closed.
