# UNSLAAD BOOK source corpus

Continuity: tes.mod.vicn.unslaad  
Primary source: translated Unslaad.esm 3.0.6

## Coverage

**50 / 50 BOOK records** from the supplied ESM are persisted in this directory as individual FormID-keyed source files.

Every BOOK record in this ESM has embedded DESC text. The source layer therefore has complete direct-text coverage for this plugin version.

## File policy

Each file preserves title, FormID, EditorID, continuity, source-plugin attribution, and decoded DESC text.

Gameplay-oriented spell/summon books are retained even when their text is only a spell name. This prevents absence from retrieval from being mistaken for an unprocessed record.

## Provenance classes

### Reused / externally sourced material — confirmed or strongly evidenced

**Loveletter From the Fifth Era** — FormID 03376B98. The existing Elder Scrolls apocryphal library independently references this text. UNSLAAD's seven Letter Fragment records 03376B91–03376B97 reproduce sections of the same Loveletter.

UNSLAAD's narrative use of the Loveletter is Vicn-continuity evidence; the underlying prose is not attributed to Vicn.

### Reused official game text

- **The 36 Lessons of Vivec: Sermon 37** — confirmed match to the official in-game book **The 36 Lessons: Sermon 37** from *The Elder Scrolls Online: Morrowind*. The prose is official ESO source material, not Vicn-authored.

### Reused unofficial developer / apocryphal text

- **The 36&9 Lessons of Vivec: Sermon 0** — confirmed match to Douglas Goodall's unofficial March-2002 forum/developer text *Sermon Zero of the Thirty-and-Six-and-Nine Sermons of Vivec*. It is not an in-game Morrowind book and is not Vicn-authored.

### External provenance unresolved

- **Vivec and Molag Bal** — no reliable pre-UNSLAAD source match has yet been found. Preserve the ESM text without assigning authorship.

### Currently treated as UNSLAAD-source texts pending contrary provenance

- Ysmir the Forefather, Volume IV
- Harakk Warrior's Final Note
- Note from Fluffy

This classification means no independent duplicate has yet been attached in the current library; it is not a claim that external provenance can never exist.

### Gameplay/spell records

The remaining records primarily teach or represent summons and frost/creature abilities, including Pot Boys, Dragon Pus/Dilon forms, Dreugh summons, Draco-Nords, Hoarfrost Guardians, Atmoran/beast summons, Dagonic Watcher, Ysgrim's Thunderbread, and other frost/conjuration effects.

## Interpretation rule

A BOOK's presence in Unslaad.esm proves that the mod distributes/uses that record. It does not by itself prove Vicn authored the text, that the in-world author is reliable, that the book's claims are objectively true, or that the text belongs to official Bethesda/ZeniMax continuity.

## Final BOOK status

**Complete:** 50 / 50 BOOK records are preserved and classified for the supplied ESM.

The unresolved external authorship of **Vivec and Molag Bal** is an accepted provenance classification after repeat verification, not an unprocessed book.

No further general BOOK extraction is required unless a newer plugin version is supplied.
