## What the faction is useful for

It provides direct implementation evidence for which forms the plugin generally treats as aligned/friendly with the Unslaad story-side rather than hostile encounter factions.

It also demonstrates that one narrative character can move across:
- different races/body forms;
- different quests;
- different physical ages/states

while retaining the same broad factional affiliation.

## Important exceptions

Not every form of a character uses this faction.

For example:
- some active Gray-Owl/Jhunal forms instead use Owl Faction or World Eater Faction;
- Ulliss's dragon form uses a dedicated Ulliss Dragon Faction;
- Austella's living combat form uses Frost Power Excursion Faction.

These differences are valuable state/form evidence, not contradictions to erase.

## Guardrail

UnslaadFaction is a gameplay alliance/story-side grouping.

It does not mean all members:
- know each other;
- share one ideology;
- exist at the same time;
- belong to one formal in-world organization.
