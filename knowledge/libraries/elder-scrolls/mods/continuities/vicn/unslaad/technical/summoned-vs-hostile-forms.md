# Summoned forms versus hostile/natural forms

Continuity: tes.mod.vicn.unslaad

UNSLAAD uses several different implementation strategies for summonable creatures.

## Same-race proxy model

These summon forms use the same custom race as hostile/boss counterparts but generally remove hostile faction membership:

- Mal-, Rein-, Ru-, Pogaan-Sinak
- Hor Priest / Hor Warrior
- Dagonic Watcher
- Draco-Nord Fonaar / Sahqon / Veddu
- Warrior of Tsun
- Storm Atronach Bear
- Hoarfrost Guardian
- Freezing Enbarr
- Rackety-Nix

This supports creature-archetype continuity without requiring individual continuity.

## Explicit hostile-faction stripping

Examples:

### Sinak
Summoned forms:
- same HM Rat/Cat/Spider/Wisp race;
- no Owl Faction;
- no Woodland-Man-Roots death list.

Hostile forms:
- Owl Faction;
- Woodland Man Roots.

### Hor / Dreugh
Summoned forms:
- same Werecrab or Dreugh Druid race;
- no Lyg Crab Faction.

Hostile forms:
- Lyg Crab Faction;
- custom Dreugh death lists.

### Dagonic Watcher
Summoned form:
- Watcher Race;
- no Dagon Faction.

Hostile form:
- Watcher Race;
- Dagon Faction;
- Watcher death list.

### Draco-Nord
Summoned Fonaar/Sahqon/Veddu:
- Dragonord Gargoyle Race;
- no 500 Companion Faction.

Hostile variants:
- same race;
- 500 Companion Faction;
- Dragonord death list.

## Pus-family proxy model

Many book-taught pus summons use dedicated proxy NPC forms that do not share the hostile custom pus race/faction directly, even though the display names match:
- Yah Miin
- Dragon Pus
- Dilon / Dilon Sivaas
- Lesion
- Brendon / Mal Brendon
- Evenaar

Hostile/natural forms instead use custom Pus races and World Eater Faction.

This makes simple name equality especially unsafe for this family.

## Unique summon-only forms

Stamina Devourer and Magicka Devourer are summon forms using Spectral Dragon Race.

Named Glow-Eel bosses share that race, but the summoned forms do not directly reuse those boss names.

## Retrieval rule

When answering lore questions:
- use the hostile/boss form for social/faction/death-history claims;
- use the summon form for spell/archetype/creature-form claims;
- merge only race/archetype identity unless a source explicitly establishes individual continuity.
