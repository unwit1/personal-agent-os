# Post-encounter artifact reconstruction model

Continuity: tes.mod.vicn.unslaad

A recurring UNSLAAD pattern is:

**encounter/quest completion -> craft recipe becomes available -> playable reconstruction of the associated gear**

Examples:

- The Owl Flies at Dusk -> Gray OWL / EGG / Shadow
- Lingering Snow -> Dragonslayer armor/greatsword/ring and Gray Owl's Mask
- Long Winter -> Delphine's Oathblade and Dragonslayer shields
- Jill trials -> Thunder-Scale gear
- VS Dreugh King -> Muatra
- VS Idol of Magnar -> Magnar set
- Remnant of Yngol death -> Yngol set
- Clone of Ayrenn death -> Oracle Iridescent Mask
- The Final Journey -> Jhunal/Hare masks and Staff of the World-Eater
- Arkved -> Staff of Bormahu / Staff of the Jills

## Why this matters

A craftable item is not automatically the same physical object previously carried by a boss or historical figure.

UNSLAAD often has:
- unplayable NPC combat form;
- death-list playable form;
- chest reward;
- independent craft recipe

for objects sharing one display name.

## Retrieval policy

Record these relations separately:

- **carried by**
- **drops/yields**
- **found in**
- **craftable after**
- **shares display identity/model with**

This avoids turning gameplay reconstruction into false historical provenance.
