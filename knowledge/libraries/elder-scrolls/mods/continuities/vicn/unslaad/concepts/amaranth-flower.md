# Amaranth Flower

Continuity: tes.mod.vicn.unslaad  
Primary source: repeatable quest zzzCrbRadiantAmarantos / Amaranth Flower  
Primary witness: Ulliss

Ulliss says **Amaranth flowers**:
- never fade;
- never wither;
- used to bloom abundantly in the garden before the land froze.

If the player recovers one, Ulliss says her mother would be pleased.

## Ontology caution

UNSLAAD also embeds and discusses texts using **AMARANTH** as a metaphysical term.

The flower's name is therefore an obvious retrieval link, but the quest dialogue does not state that the plant is literally the same thing as the metaphysical Amaranth concept.

Maintain:
- Amaranth Flower = directly evidenced local plant;
- AMARANTH = separate metaphysical/textual concept unless a later source explicitly connects them.
