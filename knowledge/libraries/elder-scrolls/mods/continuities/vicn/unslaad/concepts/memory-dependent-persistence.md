# Memory-dependent persistence

Continuity: tes.mod.vicn.unslaad

UNSLAAD repeatedly treats remembrance, song, written story, and identity as forces that preserve places or beings.

## Arkved

Arkved says:
- if a place is forgotten, it dissolves like morning fog;
- if someone remembers it, echoes remain;
- a child will laugh and sing the place into continued existence;
- the Dragonborn should sing their own self into the world or eventually fade into dreams.

This is the clearest direct formulation currently indexed.

## Anaku

In generic dialogue, Anaku discusses deliberately opaque terms THIS / THAT / IT.

One line says:
- IT sometimes talks;
- THAT will disappear if none of them remember it anymore.

The referents are unresolved, so the line is evidence for memory-dependent disappearance, not evidence identifying what "THAT" is.

## Oohoo'Laf

Oohoo'Laf says water is memory and ice functions like a library for beings of Apocrypha. He also describes Woodland Men as able to move through words.

This provides a second memory/storage vocabulary distinct from Arkved's remembrance/song formulation.

## Herkel / Herma-Mora

Herkel says Herma-Mora can conceal memories and historical events that do not suit him, while impossible memories/histories can spill from Apocrypha.

## Ja'cobee / GLENMORIL comparison

GLENMORIL's Ja'cobee says he expects everyone to forget him after the EGG finally breaks.

Because UNSLAAD has now directly connected Fluffy/Ja'cobee with the EGG and with unstable memory, this is a relevant cross-VICN retrieval link. Keep the GLENMORIL statement attributed to its own source.

## Current model

High confidence: memory/forgetting is an intentional VICN/UNSLAAD mechanism and theme.

Unresolved:
- whether remembrance literally sustains all worlds;
- whether song is a special causal technology or metaphor;
- whether "words," books, dreams, and memory use one underlying mechanism;
- how Mnemo-Li / Blue Star relates to these processes.
