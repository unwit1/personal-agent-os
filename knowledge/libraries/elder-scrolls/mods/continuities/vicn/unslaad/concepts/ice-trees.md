# Ice trees

Continuity: tes.mod.vicn.unslaad  
Primary witness: Naghu the Gardener

UNSLAAD presents ice trees as a dangerous local organism or phenomenon.

Naghu says they:
- imitate/disguise themselves as trees;
- manipulate soil to take root;
- must be thinned regularly;
- can make the land uninhabitable;
- should not simply be burned, because thawing lets them root deeper;
- can ultimately freeze the surrounding land.

The repeatable Ice Tree quest confirms that new buds continue appearing and require removal.

## Related evidence

Snow Guardian Jokul later says Atmoran ice has spread roots deeply and can only be removed by repeatedly cutting those roots back. The similar root language is worth indexing together, but Lorekeeper should not automatically declare every Atmoran ice root to be the same organism as Naghu's ice trees without a direct link.
