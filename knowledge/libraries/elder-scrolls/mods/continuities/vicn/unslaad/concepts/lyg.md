# Lyg — UNSLAAD evidence

Continuity: tes.mod.vicn.unslaad

UNSLAAD reaches **Lyg** through two independent character traditions: Herkel's Atmoran mirror route and Khev's Dreugh/Nu-Mantia doctrine.

## Herkel / mirror route

In The Final Journey, Herkel says:
- a mirror is buried beneath the ice;
- the mirror is an imitation of Magnar;
- it was made from a polished piece of **Merid-Nunda's essence**;
- it leads to an **adjacent place** called **Lyg**;
- fate can be changed there;
- the player can return by finding a connection to the original world and using a nearby mirror;
- worlds should not be mixed too freely;
- remaining there risks attention from the **Grabbers**.

This is the most concrete functional description of Lyg in UNSLAAD.

## Khev / doctrinal route

Khev the Dreugh King independently invokes Lyg in a different context.

His sermon and boss dialogue associate Lyg with:
- thirst;
- Merid-Nunda;
- a deep sea;
- birth from its bowels;
- a dead or silenced voice.

Khev does not explain Herkel's mirror route, and Herkel does not explain Khev's doctrine.

Treat them as two source traditions that converge on the same rare place-name without forcing every detail into one mechanism.

## Cross-VICN significance

DAc0da independently contains:
- LYG;
- Xero=LYG;
- a **mass erasure in LYG**;
- a memory project;
- Grabber/Adjacent-Place terminology elsewhere in the same continuity.

This makes Lyg a high-confidence VICN cross-work retrieval node.

What remains unresolved is whether:
- UNSLAAD and DAc0da depict the same historical episode;
- DAc0da's mass erasure explains Khev's "dead like Lyg" language;
- memory loss in Lyg is connected to UNSLAAD's broader memory-dependent persistence;
- the Grabbers are responsible for any of these effects.

Those are hypotheses, not established facts.

## Route/mechanism closure

UNSLAAD's Lyg **access mechanism** is resolved more strongly than its history.

Resolved inside UNSLAAD:
- Herkel identifies the under-ice mirror as a route to Lyg;
- The Final Journey objectives require using that mirror to bypass the ice seal;
- VMAD directly wires `DoorLyg`, `Alias_IceMirrorMarker`, `Alias_LygMidMarker`, and `Alias_LygEndMarker`.

Therefore **mirror-mediated Lyg transit** is a hard quest-level relationship.

Still intentionally unresolved:
- whether Khev's Lyg refers to the same episode/location-state Herkel accesses;
- whether DAc0da's LYG erasure event explains UNSLAAD's local testimony;
- whether Grabbers caused the memory effects;
- whether Lyg memory loss is the same mechanism as Mnemo-Li/Radiance persistence phenomena.

Those remain cross-source hypotheses, not unfinished ingestion.
