# Retrieval budget guideline

For most questions:
- 1 primary entity/concept page;
- 1 structural/source page;
- 1 parent cross-VICN page if needed.

Only retrieve raw source text when:
- wording matters;
- provenance is disputed;
- two pages conflict;
- the user asks for exact evidence.

This map exists specifically to reduce token/context bloat.

## Reliability-first routing

When a topic is identity-sensitive, contradictory, dream-based, or externally sourced, load `analysis/source-reliability-matrix.md` before expanding.

High-risk topics include:
- Jhunal / Gray Owl identity;
- Khev / Nu-Mantia;
- Hermit dreams / Radiance;
- Herkel cosmology;
- KINMUNE / Oracle Iridescent;
- reused apocryphal texts;
- frozen-Atmora causal explanations.

For these, retrieve one direct source page plus one structural or provenance page before synthesizing.

## Completion routing note

This map is the canonical entry point for the **completed UNSLAAD 3.0.6 ingestion**.

Do not restart broad scans by default. Expand only when:
- the requested answer needs raw wording;
- a new source/version has been added;
- a specific ambiguity requires model/script/placement inspection;
- or a new cross-VICN match appears.
