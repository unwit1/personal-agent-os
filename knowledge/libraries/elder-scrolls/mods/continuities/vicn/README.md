# Vicn continuity

**Continuity ID:** tes.mod.vicn

This overlay groups the interconnected Vicn works **VIGILANT**, **GLENMORIL**, **UNSLAAD**, and **DAc0da**. Each work keeps source-level provenance while shared entities and claims can be linked at this parent layer.

## Provenance rule

A statement established in one plugin is not automatically attributed to another plugin or to official Elder Scrolls canon. Cross-work synthesis must retain evidence pointers to the originating plugin record(s).
