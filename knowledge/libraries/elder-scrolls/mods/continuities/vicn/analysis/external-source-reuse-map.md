# VICN external-source reuse map

Parent continuity: tes.mod.vicn

Purpose: distinguish **cross-work continuity evidence** from cases where multiple Vicn works reuse the same pre-existing Elder Scrolls text or apocryphal/developer source.

A shared external source can create a real interpretive bridge, but it is not by itself evidence that Vicn authored the underlying prose or that two in-world events are identical.

---

## Provenance classes

### A. Official game-text reuse

Use when the prose comes from a released Elder Scrolls game.

Examples currently verified:

#### UNSLAAD
- **The 36 Lessons: Sermon 37**
  - source: *The Elder Scrolls Online: Morrowind*
  - UNSLAAD reuses the official text and places it inside Hermit's Tower.

#### DAc0da
Six Daggerfall Totem letters:
- Queen Akorithi
- King Eadwyre
- Gortwog
- King of the Worms
- Underking
- Lady Brisienna

Source:
- *The Elder Scrolls II: Daggerfall* Totem quest correspondence.

DAc0da's adaptation resolves dynamic placeholders into static "Agent" language.

### Interpretation rule

Separate:
- **original text provenance** = official game source;
- **selection / placement / adaptation** = Vicn narrative-design evidence.

---

## B. Identified developer / obscure-text reuse

Use when authorship/source is externally identified but the text is not ordinary released-game canon.

### UNSLAAD

#### Loveletter From the Fifth Era
- reused external developer/apocryphal text;
- seven Letter Fragment records reproduce portions;
- UNSLAAD gives it a unique mechanical role as a **timeless key** to frozen-time Atmoran dream-space.

#### Sermon Zero
- by Douglas Goodall;
- originally circulated outside the games;
- embedded in Hermit's Tower.

#### KINMUNE / ANON, ANU, ANUI-EL fragments
- reused external apocryphal/developer material;
- staged in Oracle Iridescent's Workshop with Clone of Ayrenn and Oracle-Iridescent equipment.

### DAc0da

Verified Michael Kirkbride reuse includes:
- **Ghost Choir 9**
- **ANON/ANU/ANUI-EL / KINMUNE**
- **The Tsaesci Creation Myth**
- **Dominion Prism Textract**
- **et'Ada, Eight Aedra, Eat the Dreamer**
- **Lament for Pelinal**
- **A Type of Zero Still to Be Discovered**

The exact original text belongs to the external source layer.

DAc0da-specific placement, quest integration, and reinterpretation belong to the Vicn layer.

### DAc0da

**Djaf: Arena of Lyg**
- verified community-apocrypha reuse by mojonation1487.

## D. External provenance unresolved

### UNSLAAD

**Vivec and Molag Bal**
- exact pre-UNSLAAD source not reliably identified in the current corpus;
- physically grouped in Hermit's Tower with Sermon 37, Sermon Zero, and Short Muatra;
- preserve as unknown-origin text until stronger source evidence appears.

Unknown provenance is preferable to falsely assigning Vicn, Kirkbride, Goodall, or official authorship.

# Shared external substrate versus direct continuity

These two evidence types must remain distinct.

## Example: KINMUNE

### External-source layer
ANON, ANU, ANUI-EL supplies:
- KINMUNE;
- Ayrenn association;
- Oracle Iridescent identity tradition.

### UNSLAAD layer
Vicn-specific staging:
- Oracle Iridescent's Workshop;
- KINMUNE fragments;
- Clone of Ayrenn;
- Oracle Iridescent Mask.

### GLENMORIL layer
Direct Vicn evidence independently uses:
- Oracle Iridescent as source of Oneiromancer dream-travel knowledge.

This creates a genuine cross-Vicn **Oracle Iridescent** thread, but the KINMUNE identity should remain source-aware.

## Example: Loveletter

### External layer
The Loveletter supplies its original prose and Nu-Mantia/Liberty vocabulary.

### UNSLAAD layer
- fragment hunt;
- Hermit reconstruction;
- timeless-key mechanic;
- Khev's contradictory Nu-Mantia interpretation.

A contradiction between Khev and the Loveletter is meaningful Vicn interpretation, not evidence that Vicn authored the Loveletter.

## Example: Ghost Choir 9

### External layer
DAc0da embeds the verified Michael Kirkbride Ghost Choir 9 text.

### Direct Vicn layer
DAc0da also contains:
- Ghost Choir 9 organization/quest material;
- LYG;
- memory-project / mass-erasure material.

UNSLAAD independently contains implementation-tagged:
- GC9 message;
- LYG-sector memory evaporation;
- timeline disposal.

The cross-work bridge is strong because of **independent implementation use**, not merely because one mod embeds an external GC9 text.

# Retrieval policy

When a query touches a reused text:

1. retrieve the canonical external-source/provenance entry;
2. retrieve each Vicn work's **placement/use** dossier separately;
3. distinguish:
   - what the original text says;
   - what the mod does with it;
   - what later characters say about it;
4. only call something a cross-work Vicn bridge when there is independent in-mod evidence beyond shared quotation.

# Claim labels

Recommended internal labels:

- `official-text-reuse`
- `developer-text-reuse`
- `community-apocrypha-reuse`
- `external-provenance-unresolved`
- `vicn-authored-placement`
- `vicn-authored-interpretation`
- `direct-cross-work-continuity`
- `shared-external-substrate-only`

These labels should keep source attribution intact while still allowing the Lorekeeper to explain why Vicn selected a particular text.
