## Retrieval policy

For a question spanning more than one Vicn work:

1. retrieve the most specific parent relationship page;
2. retrieve one source-specific dossier from each relevant work;
3. retrieve raw dialogue/book/message text only if exact wording or provenance matters.

Do not use a parent page as a replacement for source attribution.

## Confidence policy

A parent thread may be created when at least one of these is true:

- the exact named identity recurs in multiple works;
- a distinctive exact phrase/concept recurs independently;
- one work directly names a person/event from another;
- implementation evidence plus independent dialogue creates a strong bridge.

Do not promote a relationship based only on:
- broad Elder Scrolls lore overlap;
- similar visual design;
- generic words such as dream, memory, dragon, or star;
- one source's speculation projected into another work.
