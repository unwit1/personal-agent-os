# Brain-Billies — cross-VICN thread

Parent continuity: `tes.mod.vicn`

This page tracks the rare exact term **Brain-Billies** across VICN works while separating what each source actually says they do.

## DAc0da

DAc0da unique NPC **Mecha-Kanra** says Brain-Billies are local spirits that:

- sting a person's memories;
- cause forgotten things to be remembered;
- can be eaten to help prevent forgetting.

Evidence: `DAc0da.esm:00D051`, `00D053`.

DAc0da also implements Brain-Billies mechanically through:

- `zDcdMgEBrainBillies`;
- `zDcdFoodBrainbillies`;
- a memory-spirit/needle effect;
- a system in which repeated use contributes toward **Mnemolic Sign**.

This makes the DAc0da mechanism explicit: Brain-Billies are tied to **memory stimulation/recovery**.
