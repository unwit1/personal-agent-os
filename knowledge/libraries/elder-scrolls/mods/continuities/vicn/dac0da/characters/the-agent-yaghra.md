## Daggerfall identity coding

The MQ01 Agent's ash pile contains a leveled list consisting entirely of the six **Totem of Tiber Septim correspondence letters** from the Daggerfall/Warp-in-the-West story.

That placement is direct DAc0da evidence linking this Agent family to the Daggerfall Agent identity cluster.

MQ04 later makes the connection conceptually explicit by discussing a Warp-in-the-West Agent as a Prisoner candidate.

## Ontology caution

The library should not state that each Yaghra body is literally the unchanged historical Daggerfall protagonist.

DAc0da's broader ontology includes:

- alternate fate bodies;
- copied personalities/memories;
- Many Paths;
- de-assignment/quantum instability;
- mnemolichite reconstructions.

Therefore these forms are best modeled as **DAc0da Agent manifestations/bodies associated with the Daggerfall Agent**, with exact identity continuity left source-scoped per scene.
