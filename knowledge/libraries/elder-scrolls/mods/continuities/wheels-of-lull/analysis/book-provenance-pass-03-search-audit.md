# Wheels of Lull book provenance — pass 03 search audit

Continuity: `tes.mod.wheels-of-lull`  
Scope: prior-source discovery audit for the remaining named works after deterministic fingerprinting.

## Method

This pass searched exact titles, distinctive author/byline strings, and distinctive opening phrases across:

- the repository's central Elder Scrolls source corpora;
- Imperial Library / developer-text search surfaces;
- archived Elder Scrolls discussions;
- Nexus/Trainwiz mod-history pages;
- broad web indexes used only for discovery.

A result is not treated as provenance evidence merely because it reproduces the same text. To establish **prior reuse**, the source must either predate Wheels or independently identify an earlier source/edition.

## Harquebuses — concept preexistence confirmed, exact treatise still unresolved

Record: `0537158D` — *Harquebuses*

Pre-Wheels evidence confirms that Trainwiz's **Aethernautics** already contained harquebuses. A September 2012 Aethernautics weapon-tweak page explicitly describes the weapons as harquebuses from Trainwiz's Aethernautics and credits Trainwiz's original designs. The later Aethernautics page likewise describes five harquebus types and the shared Trainwiz continuity.

This strengthens the existing `probable_legacy_trainwiz_material` classification for the **technology/concept**.

It still does **not** prove that the exact Wheels BOOK treatise — *On the Propulsion of Matter, Mind, and Mathematics via Magickal Means...* — was published before Wheels. No exact prior text witness was located in this pass.

Status remains:
- concept/terminology predates Wheels: **verified**
- exact BOOK text predates Wheels: **unverified**
- promotion to exact external-text reuse: **blocked**

### Search interpretation

- Exact-title searches did not locate a trustworthy earlier publication for these texts.
- Broad/fuzzy matches to generic terms such as "power", "moon", or "mutability" were discarded.
- A repository fuzzy match suggesting *Musings On Power* in the ESO corpus was manually checked and did not contain the exact title.
- A 2015 Trainwiz Nexus article uses Sybandis terminology, but it postdates Wheels and therefore cannot establish prior-source reuse.
- A later community translation/discussion explicitly labels *Journeys through Sybandis* as a fictional text from *The Wheels of Lull*. This is useful attribution evidence for later circulation, not proof of original authorship.
- Later Wheels mirrors/transcriptions of *Chronography* are downstream witnesses and are not promoted to prior sources.

## Negative-evidence rule

"No earlier source found" is stored only as a **search result state**, never as proof that Trainwiz first authored the text for Wheels.

These records remain eligible for future promotion if an archived pre-release mod asset, forum post, developer-text collection, or other dated witness is discovered.
