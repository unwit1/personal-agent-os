# VIGILANT books and notes

The supplied `Vigilant.esm` contains **179 BOOK records**. The local extraction preserves decoded `DESC` text for all 179 records.

This directory is the persistent source-text layer. Story-critical journals, reports, letters, and lore documents are being committed first; remaining spell/conjuration books and lower-priority notes can be added incrementally without changing the normalized claim layer.

Book text remains scoped to `tes.mod.vigilant`. A book's statements are in-world documentary evidence and may be biased, mistaken, damaged, or deliberately misleading.
