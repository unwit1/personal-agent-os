## Modeling rule

A faction/institution dossier should distinguish:
1. established Elder Scrolls substrate;
2. VIGILANT-specific events and membership;
3. Coldharbour reconstruction or manifestation;
4. gameplay/form classes that are not necessarily historical factions.

In particular:
- Soul-Shriven is primarily an ontological/encounter class;
- Alessian Sleeper is primarily a body/race implementation class;
- neither should automatically replace a character's historical institutional identity.
