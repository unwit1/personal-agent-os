## Literary source

The note reproduces the opening stanza of Thomas Gray's *Elegy Written in a Country Churchyard*.

The excerpt ends with the speaker alone as the world passes into darkness.

The poem predates VIGILANT and is not an in-world Elder Scrolls composition.

## Itinerary function

The eight-note sequence begins with:
- a body in a sarcophagus

and ends with:
- the dead Slave Trader in a cemetery;
- a graveyard poem.

This strongly supports an intentional beginning/end structure for the note trail.

It does not prove the eight notes are a literal chronological diary.
