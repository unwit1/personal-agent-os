# Dreamcatcher

Form ID: 0532F8C4
Continuity: tes.mod.dealing-with-daedra

The Dreamcatcher is an enchanted amulet whose item description says it allows "collection and redistribution of dying memories."

Its associated magic system includes Waking Nightmare, a spell described as afflicting a living target with a dying memory and potentially provoking fight-or-flight behavior.

This artifact is important because memory transfer is a recurring technology in the mod:
- Sadren Sarethi blends Wispmother and mortal memories;
- the anti-dragon gem transfers old Dragon-Cult/necromantic memories;
- dragon memories can be partially harvested;
- Shadow/Apocrypha dream sequences teach knowledge;
- the Dreamcatcher packages dying memory as a portable offensive resource.

The artifact therefore supports a broader continuity theme in which memory is treated as something magical systems can capture, move, weaponize, or use as evidence.
