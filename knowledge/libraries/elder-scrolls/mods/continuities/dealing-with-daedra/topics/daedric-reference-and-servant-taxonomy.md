# Daedric reference and servant taxonomy

Continuity: tes.mod.dealing-with-daedra
Primary source: BOOK 0556D012, The Daedric Princes and Their Servants.

This book is an in-world occult reference work listing Princes, alternate names, spheres, realms, and characteristic servants.

Examples include:
- Clavicus Vile -> Barbas and Skaafin;
- Hermaeus Mora -> Seekers and Lurkers;
- Nocturnal -> Shrikes;
- Meridia -> Aurorans;
- Mephala -> Spider Daedra;
- Sheogorath -> Mazken and Aureals;
- Molag Bal -> vampires and enslaved lesser Daedra.

The book describes Seekers and Lurkers as corrupted mortals. That is a source claim, not automatically an objective species origin.

A parenthetical reader annotation at the end concludes that the Gray-Wave family's final generation must have traded newborns to Hermaeus Mora to be transformed into Seekers and points toward the Hunting Lodge. This annotation is evidence for a quest deduction, not part of the reference author's neutral taxonomy.
