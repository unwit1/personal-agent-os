# LEGO Minifigure Customs — Brickmen Routing Pointer

The canonical repository for LEGO customs and custom-minifigure research,
knowledge, datasets, schemas, prompts, evaluation protocols, ingestion
tooling, and related automation is:

https://github.com/unwit1/brickmen

Personal Agent OS may index, route to, orchestrate, and reference Brickmen,
but should not maintain a second canonical copy of Brickmen-owned material.

New LEGO/custom-minifigure knowledge and tooling belongs in Brickmen.

Any additional LEGO-related files retained elsewhere in Agent OS should have
a cross-project or personal-context purpose rather than duplicate Brickmen's
canonical corpus.
