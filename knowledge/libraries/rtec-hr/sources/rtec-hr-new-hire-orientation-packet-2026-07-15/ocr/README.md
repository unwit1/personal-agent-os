# OCR search text

These text files were produced locally with EasyOCR from rendered pages. They exist to make the scanned source PDFs searchable. They are not authoritative transcripts: OCR can misrecognize words, numbers, punctuation, URLs, and reading order. The original PDFs in `../source/` control. Every source page was also visually inspected; known OCR correction for the school-bus statistic (19 injuries, not 191) is recorded in `../reference-notes.md`.
