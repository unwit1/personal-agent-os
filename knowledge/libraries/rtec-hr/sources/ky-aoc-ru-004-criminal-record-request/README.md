# Kentucky AOC-RU-004 Records Check Request

This folder preserves the official, unchanged Kentucky Court of Justice AOC-RU-004 PDF and a searchable text extraction. The form is labeled Rev. 12-22. The official Legal Forms listing displayed it on 2026-09-23 as the Records Check Request.

The 2026 RTEC email thread that referenced this form asked whether it could replace a prior form in an employment application packet; the thread does not establish approval or implementation. The official Kentucky Court of Justice Legal Forms guidance says alteration beyond completion is prohibited. Keep this source unchanged and do not treat it as an approved RTEC procedure.

The form contains blank SSN, driver's-license, date-of-birth, and other identity fields. Completed applicant forms and applicant data remain outside this repository. See `manifest.json` for provenance, hash, and handling rules. The PDF controls; the extracted text is for search only.
