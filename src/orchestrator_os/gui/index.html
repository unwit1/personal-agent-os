        Session foreman 
        
        The foreman plans every run you start while it is set: it breaks the goal into tasks and picks which model runs each one.
        
        
        
        
        
        
          
          
        
        
        
        
        
          
        
            
            
          
        
          
          
        Pay per token with your OpenRouter key: no GPU, no idle cost. Set a credit limit on the key in OpenRouter; it is the hard cap.
        
          
        
        
        
        
        
          
        
            
            
          
        
          
          
        Any OpenAI-compatible server: Ollama (port 11434), LM Studio (1234), llama.cpp, vLLM (8000). Nothing is rented or billed.
        
          
        
        
        
        
        
        
        Agent OS rents the cheapest GPU that fits the model, starts it, and shuts it down before the job budget runs out, or after every attached run has planned and it has been idle for a while.
        
        
        
          
          
          
        
        
        
        
        
          
          
          
        
        
        
        
        
        
        
        
      
        
    
        

    
        
      
        
        AI models 
        
        Agent OS checks the official Claude and OpenAI model lists and the Codex app's own list every day (no AI model is used for this). Newer versions of the same model are used automatically; switching to a different model waits for you.
