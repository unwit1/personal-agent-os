# Lorekeeper knowledge libraries

This directory holds evidence-backed lore libraries and project continuities.

## Continuity rule

Material from mods, adaptations, personal projects, fan works, or alternate canons must live in an explicit continuity overlay. Claims from an overlay may be compared with base Elder Scrolls sources, but they must not be silently promoted into base canon.

A continuity should retain source provenance and raw extracted evidence separately from normalized entities/claims so later indexing or model summaries can be regenerated without losing the original evidence.
