# Semantic pass 13 — batch 28: Rift Bank public services and Thieves Guild deterrence

This batch analyzes two public/criminal bulletins concerning the Rift Bank and Mineral Exchange.

## Public-facing bank

An older/yellowed advertisement (BOOK 058B8FB7) places the bank in an old Dwarven storehouse east of Fort Greenwall between Riften and Shor's Stone.

It advertises:
- business/venture funding;
- gemstone and precious-metal services;
- secure storage of valuables;
- new customer accounts.

This independently supports the bank as a normal financial institution rather than only Aedwatch's private collection site.

## Thieves Guild casing attempt

BOOK 057D9049 begins as a proposal to case the bank for a major robbery.

An edit attributed to Brynjolf calls the plan a fool's errand because security is too tight.

The note then keeps a tally of people who ignored the warning, divided into dead and life-in-prison outcomes.

The tally is stylized rather than a fully identified incident report, but it strongly supports the bank's security reputation.

## Significance

The two notices provide opposing external views:
- customers see financing, storage, and mineral exchange;
- thieves see a tempting high-value target whose security is strong enough to deter Brynjolf.

This converges with Aedwatch's own correspondence boasting about trained security without relying solely on his self-assessment.
