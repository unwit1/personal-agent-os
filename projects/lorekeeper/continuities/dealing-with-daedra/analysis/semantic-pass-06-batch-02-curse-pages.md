# Semantic pass 06 — batch 02: Book of Curses page placements

This batch is deliberately limited to the six physical pages and their collection route.

A binary record pass over the ESP resolved each page ACTI to its placed REFR and enclosing CELL group. This provides stronger evidence than inferring page identity from the Master's dialogue sequence.

Verified mapping:
1. Agony -> Anise's Cellar.
2. Despair -> Drelas' Cottage.
3. Vulnerability -> Harmugstahl.
4. Binding -> Rannveig's Fast.
5. Petrification -> Southfringe/Bashnag's base.
6. Unlife -> Ansilvund Burial Chambers.

The Master possesses the spine, not a page, and says he can scry on remaining scraps to locate the distributed pieces.

This establishes the Book of Curses as a deliberately fragmented artifact/game with at least seven distributed components if the spine is counted separately.
