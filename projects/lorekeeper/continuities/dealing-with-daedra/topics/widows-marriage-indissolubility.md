# Widows branch: marriage and the no-divorce response

Continuity: tes.mod.dealing-with-daedra

After the Lunglef drunken-marriage sequence, the player can seek relief through a small shared set of Temple-of-the-Divines priest actors.

When told the player was drunk, the priest response is that Skyrim interprets Mara's teaching on commitment as unbreakable.

The player is told to return home and make the best of the marriage.

## Narrative function

Inside the Widows storyline this does three things:
- prevents an immediate mundane exit from the spouse relationship;
- reinforces that the marriage is socially recognized despite intoxication;
- raises the betrayal value of Lysara's later demand for spouse murder.

This is mod-continuity dialogue, not a claim that all Elder Scrolls marriage law universally forbids divorce.
