# Knight Mentor Signet

Form ID: 05150ABB
Continuity: tes.mod.dealing-with-daedra

The Knight Mentor Signet is both badge and magical tool.

Its item description says it:
- manipulates a target's residual Shadows;
- allows nearly effortless Shadow magic or collection of Shadows for the Font;
- depends on Shadows that regenerate over time;
- can be shattered to teleport the wearer back to the School.

Charged variants explicitly track Lightly, Moderately, and Fully Charged states.

## Corruption path

After gaining Daedric insight into Shadow magic, the player receives an option to modify the signet.

The corruption message says the user now understands how the ring harnesses latent Shadows and can turn that mechanism into general assistance with Shadow casting.

The resulting Corrupted Signet loses the original properties but makes Shadow magic easier to cast.

The implementation script removes the ordinary signet and replaces it with the corrupted version only when the player has the relevant Shadow-gate understanding.

This creates a concrete mechanical tension between institutional Julianos utility and individually optimized Daedric-derived technique.
